Thank you for your interest in the Probabilistic Decoding Across Time (PDAT) toolbox for MATLAB!  
This toolbox should help you get started if you are trying to decode posterior probability distributions from time series brain signals.  
The main functionality of the toolbox lives in the "TAFKAP_decode.m" and its dependencies. "uncertainty_eeg_cupcake.m" is the wrapper function we used in our publication, and should serve as a useful demonstration of how to prepare data for the decoding analysis.
